FITNESS RPG — Android-ready web app starter

WHAT'S INCLUDED
- XP, levels and ranks
- Daily quests with one-time-per-day XP
- Skill tree milestones
- Workout-day and streak tracking
- Optional weight log
- Export/reset data
- PWA manifest and offline service worker

FASTEST WAY TO TRY IT
1. Extract this ZIP.
2. Open index.html in a browser to preview (some PWA features need hosting).
3. To install it like an Android app, publish the folder to a free HTTPS static host such as GitHub Pages.
4. Open the hosted link in Chrome on Android, tap the three-dot menu, then "Add to Home screen" or "Install app".

IMPORTANT
- This is Version 1, a browser-based installable app, not a signed APK yet.
- Data is stored locally in the browser on this device. Clearing browser data may erase it.
- The app is a habit tracker, not medical advice. Adjust training to your ability and recover adequately.
